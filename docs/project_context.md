# Project Context

## Project Name

KodWebsite

## Description

KodWebsite is the official website for the KOD team. It works as a public presentation website and portfolio for the team.

The site should explain who the team is, what services or projects it offers, show previous or future work, and provide a professional way for visitors to contact the team.

## Current Stack

- Astro
- TypeScript
- CSS
- Vercel
- Optional Rust/WebAssembly module in `wasm/`

## Main Goals

- Present the KOD team professionally.
- Show projects and portfolio work.
- Explain services clearly.
- Provide a contact section or contact form.
- Keep the website fast, clean, responsive and easy to maintain.
- Avoid unnecessary complexity.

## Target Style

The website should feel:

- Modern
- Professional
- Clean
- Technological
- Trustworthy
- Easy to navigate

Avoid making the site look like a generic template.

## Main Sections Expected

Possible sections:

- Home
- About / Team
- Projects / Portfolio
- Services
- Contact

Only implement sections when requested or when they already exist in the project.

## Development Priorities

1. Clear structure.
2. Visual consistency.
3. Responsive design.
4. Maintainable components.
5. Good documentation.
6. Simple deployment.

## Deployment

The project is intended to be deployed on Vercel.

Before deployment, check:

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
